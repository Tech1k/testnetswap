Support the project

TestnetSwap is free, open-source (AGPL-3.0), and non-custodial. The swap service itself only moves testnet coins, so it never touches real funds. Running the nodes, monitoring, and maker behind it isn't free, though. If it's useful to you, a voluntary mainnet tip toward hosting and development is appreciated, but never required. Thank you.

OpenAlias one name, any coin

Wallets with OpenAlias support (Monero GUI/CLI, Cake, Feather, MyMonero and others) resolve a single human-readable name to the right address automatically.

Other ways to help

Star the project

Tell other testnet developers about it. More users means a livelier testnet playground for everyone.
