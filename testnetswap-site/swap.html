Heads up

Give it time, keep this tab open

Swaps settle at testnet block speed: usually minutes, but sometimes an hour or more when blocks are slow. An atomic swap needs your browser to finish its half (claiming the coin you're buying), so leave this tab open and it completes on its own. Closing it mid-swap is safe: no one can take your coins, and you can reclaim your deposit after the refund deadline.

Your keys, this browser

Each swap uses a fresh key generated and held only in this browser (localStorage), used once and then done. The deposit address is yours; nobody else can spend it.

How the tLTC leg is verified

Before revealing anything, your browser checks the maker's on-chain lock against a block explorer. tBTC uses mempool.space (independent); tLTC currently uses testnetscan.com, run by this operator, because there's no reliably-synced independent Litecoin-testnet explorer right now. On testnet that's an accepted tradeoff. With real value you'd want an independent explorer. The tLTC → tBTC direction isn't affected.
